    What this is
    
      
    The lab station for the AI vision colour sorting project in your browser: a Niryo One, the platform with its four markers, squares A, B and C, foam cubes and the camera. The project's Python programs run here unchanged, in the browser, with the same windows, keys and robot commands as in the lab.
    
      
    Running a program
    
      
      
        
    1. Choose the program at the top (they are in step order), add options if needed (for example --measure-offset for step 4) and press Run.
      2. 
        
    2. Windows open on top of the page. Click a camera picture before pressing a key: as in the lab, it only receives keys when selected. Drag a window by its title bar; drag its bottom-right corner to make it smaller or larger.
      3. 
        
    3. Stop works like Ctrl+C. Restart Python is for a program that does not stop.
      4. 
      
    
      
    Editing your code
    
      
    Opening a program in Files and editor selects it for Run (programs that run on their own: the steps, main.py, files with if __name__ == "__main__":). The terminal is shown under the editor: drag its bar to resize it, or hide it.
    
      
    Open Files and editor, choose a file, edit it and press Ctrl+S. + File and + Folder create new ones in the selected folder (type a path such as LAB-5/main.py to make the folder too); Rename also moves, or drag a file or folder onto another folder (onto the empty space below the list for the top level); Delete removes the selected file or folder. A new .py file appears in the Run list. Your files, dataset, model and results are kept in this browser only: nobody else sees them, and what you add, move or delete does not change anyone else's copy. Another browser or PC starts with fresh files, and clearing the browser's site data deletes yours, so use Download project to keep a copy or move it to a lab PC, and Upload .zip to bring it back. The vision sorting project is in the AI-VISION-SORTING folder and the labs in LAB-1 to LAB-4; files you delete or move stay that way, and Put back the original program files brings back every original file.
    
      
    The station
    
      
      
        
    • Drag the view to turn it, right-drag to pan, wheel to zoom.
      • 
        
    • Drag a cube to move it, use the wheel over a cube to turn it (Shift = 15° steps), double-click it to remove it. Let go of a cube over hole A, B or C and it drops in; up to 3 cubes stack in each hole. "Add a cube to hole A" puts one straight in.
      • 
        
    • Move the joints by hand opens six joint sliders and gripper buttons. They work while a program has learning mode on (Lab 3 teach mode: move the joints, then press s or g in the terminal), or when no program is connected.
      • 
        
    • Click × on the camera picture to hide it, and Show camera to bring it back.
      • 
        
    • In the camera windows the arrow keys work as in the lab (guided picks in step 4: LEFT/RIGHT turn the gripper, UP/DOWN change the height).
      • 
        
    • As on the real robot, a move that presses the gripper on a cube or into the platform stops with a "collision" error.
      • 
        
    • Learning mode (step 1.1): drag on the platform to move the gripper; click the 3D view, then use the arrow keys (Shift = 5 mm), PgUp and PgDn for height, and [ ] to turn.
      • 
        
    • The camera behaves like the lab's: automatic exposure and colour change when a hand or the arm is in view, and the focus hunts until step 1.3 locks it.
      • 
        
    • Use Desk lamp for the lighting test in step 3 (collect it with --dataset dataset_lighting2).
      • 
      
    
      
    Real robot and camera (in the lab)
    
      
      
        
    • On the robots' Wi-Fi, open Real robot and camera, type your robot's IP address and press Start shadow: the 3D arm follows the real arm. The page only reads the robot; it never moves it. Chrome or Edge asks once to "connect to devices on your local network": press Allow. You can run the lab programs in PyCharm at the same time.
      • 
        
    • If the robot is not calibrated, the 3D arm does not match the real one: the page says so.
      • 
        
    • Camera: plug the station's USB camera into this computer, press Find USB cameras (allow the camera), and choose it. The programs and the preview then use the real camera.
      • 
      
    
      
    Differences from the lab
    
      
      
        
    • Choose the robot Simulator in step 1.1; its Lab 5 positions can be loaded.
      • 
        
    • While the robot moves in steps 1.5 and 4, the camera picture pauses; it updates again when the move ends (the 3D view keeps moving).
      • 
        
    • Voice commands use the browser's speech recognition (Chrome or Edge), or words typed in the voice box.
      • 
        
    • The simulated pictures are cleaner than the real camera: expect higher accuracy here than in the lab. Final results for your report come from the real station.
